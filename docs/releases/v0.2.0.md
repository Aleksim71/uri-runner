# URI-RUNNER v0.2.0 — WORKING RELEASE

## Status

Working release for real project rollout.

Primary validation target: Tempasi.

## Included in this release

- scenario runtime
- watcher flow
- project-owned routing
- browser flow
- diagnostics and artifact persistence
- policy / capability layer
- valid failure outbox contract
- one-shot watcher command: `uri watch --once`

## Release contract

This release is considered working if:

- CLI starts and executes the expected flow
- watcher processes intake correctly
- success runs produce valid outbox artifacts
- failure runs also produce valid outbox artifacts
- browser scenario flow works in real execution
- project-owned routing remains stable
- real truth tests pass

## Intended usage

This is the first practical release intended for rollout on a real project rather than only internal draft validation.

## Known limits

- protocol is still evolving
- some flows may still be refined after Tempasi rollout
- release is practical, not final architecture freeze

## Validation target

Tempasi is the first real-world validation environment for this release.

## Next step after release

- run smoke cycle on Tempasi
- collect gaps
- ship fix release if needed
